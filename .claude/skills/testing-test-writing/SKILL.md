# Testing Test Writing

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle testing test writing.

## When to use this skill

- When writing tests at logical completion points after feature implementation
- When creating tests for core user flows and critical business paths
- When testing behavior and outcomes rather than implementation details
- When writing clear, descriptive test names that explain expected outcomes
- When mocking external dependencies like databases, APIs, or file systems
- When ensuring tests execute quickly (milliseconds for unit tests)
- When focusing on primary workflows rather than edge cases during development
- When deferring non-critical testing until dedicated testing phases
- When working with test files in tests/, test/ directories or files like test_*.py, *_test.py
