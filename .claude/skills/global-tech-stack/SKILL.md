# Global Tech Stack

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global tech stack.

## When to use this skill

- When making decisions about which frameworks or libraries to use
- When setting up development environments and configuring build tools
- When selecting testing frameworks, linters, or code quality tools
- When choosing databases, ORMs, or data storage solutions
- When integrating third-party services for authentication, email, or monitoring
- When configuring package managers (pip, npm, bundler, etc.)
- When ensuring consistency with the project's established technology choices
- When onboarding new tools or upgrading existing dependencies
- When working with framework configurations, requirements.txt, pyproject.toml, package.json, or tech stack documentation
