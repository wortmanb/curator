# Global Coding Style

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global coding style.

## When to use this skill

- When writing new code in any programming language (Python, JavaScript, TypeScript, etc.)
- When naming variables, functions, classes, or files across the codebase
- When formatting code with consistent indentation, line breaks, and spacing
- When refactoring code to follow the DRY (Don't Repeat Yourself) principle
- When creating small, focused functions that do one thing well
- When removing dead code, commented-out blocks, or unused imports
- When applying automated formatters (Black, Prettier, etc.) or linters (Ruff, ESLint)
- When ensuring code is self-documenting with meaningful, descriptive names
- When writing code that does not require backward compatibility unless specified
