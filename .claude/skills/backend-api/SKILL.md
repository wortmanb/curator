# Backend API

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend API.

## When to use this skill

- When creating or modifying RESTful API endpoints and route definitions
- When writing API controllers, handlers, or views that process HTTP requests
- When implementing API versioning strategies or updating API versions
- When designing resource-based URL structures and endpoint patterns
- When configuring HTTP methods (GET, POST, PUT, PATCH, DELETE) for resources
- When setting up query parameters for filtering, sorting, pagination, or search
- When defining API response formats and HTTP status codes
- When implementing rate limiting or API usage management
- When working with files like api.py, routes.py, controllers/, views/, handlers/, or endpoint definitions
