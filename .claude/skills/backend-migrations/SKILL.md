# Backend Migrations

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend migrations.

## When to use this skill

- When creating new database migration files for schema changes
- When modifying existing database tables, columns, or constraints
- When adding or removing database indexes for performance optimization
- When implementing rollback/down methods for migration reversibility
- When separating schema changes from data migrations
- When handling zero-downtime deployment considerations
- When managing database version control and migration history
- When working with migration files in migrations/, alembic/, db/migrate/, or similar directories
- When creating or modifying migration scripts for database schema evolution
