# Global Validation

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global validation.

## When to use this skill

- When validating user input from CLI arguments, configuration files, APIs, or any external sources
- When implementing server-side validation for security and data integrity
- When adding client-side validation for immediate user feedback
- When sanitizing input to prevent SQL injection, command injection, or path traversal attacks
- When checking data types, formats, ranges, and required fields
- When validating business rules like sufficient balances or valid date ranges
- When using allowlists to define what is permitted rather than blocklists
- When providing specific, helpful error messages for invalid input
- When working with CLI argument parsers, API endpoints, validation schemas, or data processing code
