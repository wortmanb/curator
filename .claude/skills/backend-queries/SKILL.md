# Backend Queries

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend queries.

## When to use this skill

- When writing database queries using ORM methods or raw SQL
- When implementing data fetching and retrieval logic
- When optimizing queries to prevent N+1 query problems with eager loading
- When using parameterized queries to prevent SQL injection vulnerabilities
- When selecting specific columns instead of using SELECT *
- When implementing transactions for related database operations
- When adding query timeouts or implementing caching for expensive queries
- When using WHERE, JOIN, or ORDER BY clauses that need proper indexing
- When working with repository patterns, query builders, or data access layers
