# Global Commenting

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global commenting.

## When to use this skill

- When writing code that needs minimal, strategic comments to explain complex logic
- When documenting non-obvious implementation details or algorithms
- When clarifying intent for code that cannot be made more self-explanatory
- When adding concise explanations for large sections of code logic
- When reviewing existing comments to ensure they are evergreen and future-relevant
- When avoiding comments that describe recent changes, temporary fixes, or historical context
- When prioritizing self-documenting code through clear naming and structure
- When working with any code files that may benefit from minimal, helpful commentary
