# Backend Models

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend models.

## When to use this skill

- When creating new database model or entity classes
- When defining table structures, columns, and data types
- When implementing model relationships (one-to-many, many-to-many, foreign keys)
- When adding database constraints (NOT NULL, UNIQUE, foreign keys)
- When setting up timestamps (created_at, updated_at) on models
- When defining model-level validations and data integrity rules
- When adding indexes to model fields for query performance
- When configuring cascade behaviors for related records
- When working with files in models/, entities/, orm/, or database schema definition files
