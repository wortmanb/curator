# Global Conventions

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global conventions.

## When to use this skill

- When organizing files and directories in a predictable project structure
- When writing clear commit messages and managing version control workflows
- When creating or updating README files, documentation, or contribution guidelines
- When configuring environment variables and avoiding hardcoded secrets
- When managing project dependencies and keeping them up-to-date
- When establishing code review processes and pull request descriptions
- When implementing feature flags for incomplete features
- When maintaining changelogs or release notes for project changes
- When working with configuration files like package.json, requirements.txt, pyproject.toml, .env, or project docs
